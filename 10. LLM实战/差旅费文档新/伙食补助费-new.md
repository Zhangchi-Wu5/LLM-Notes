## 一、伙食补助费实施细则
<!-- {rule_type:"报销条件", level:"重要"} -->

### 1.1 基础报销条件
- **常规要求**：  
  ✓ 必须提供住宿费发票和城市间交通费票据  
  ✓ 部分天数有住宿发票的需分段计算补助  

- **特殊情形**：  
  ✓ 出差地有住所（住自己家）  
  ✓ 边远地区无法取得住宿发票  
  ➤ 需经单位领导批准并书面说明 <!-- [KEY_RULE] -->  
  ✗ 其他无住宿发票情况不予报销

### 1.2 票据缺失处理
| 票据缺失类型       | 替代凭证            | 报销标准调整                             |
| ------------------ | ------------------- | ---------------------------------------- |
| 无交通票据         | 住宿费发票          | 温州外减半至40元/天 <!-- [TABLE_ROW] --> |
| 当天往返无交通票据 | 公务审批单+出行证明 | 减半报销                                 |
| 会议/培训无票据    | 会议通知+出行证明   | 往返途中减半报销                         |

## 二、伙食补助费补助标准
<!-- {data_type:"阶梯标准", dimensions:["地区","职称"]} -->

### 2.1 地区对照表
| 地区类型  | 正高职称 | 副高职称 | 其他人员                         |
| --------- | -------- | -------- | -------------------------------- |
| 一般地区  | 无       | 无       | 100元/天包干 <!-- [KEY_RULE] --> |
| 特殊地区* | 无       | 无       | 120元/天包干 <!-- [KEY_RULE] --> |

> *特殊地区定义：西藏自治区、青海省、新疆维吾尔自治区全境

## 三、术语定义
<!-- {rule_type:"基础定义"} -->

### 3.1 人员分类
- **正高职称**：教授级/研究员级专业技术人员  
- **副高职称**：副教授级/副研究员级专业技术人员  
- **其他人员**：未达到上述职称标准的在职员工

### 3.2 地区说明
- **一般地区**：除特殊地区外的中国大陆区域  
- **特殊地区**：  
  ✓ 西藏自治区（全境）  
  ✓ 青海省（全境）  
  ✓ 新疆维吾尔自治区（全境）
