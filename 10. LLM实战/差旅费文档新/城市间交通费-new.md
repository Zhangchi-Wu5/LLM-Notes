以下是医院城市间交通费管理规范

▨▨▨

## 一、交通工具保险规定



### 1. 1**已参保人员**
  - **适用对象**：  
    ✓ 医院统一购买公共交通意外险的正式员工
  - **禁止事项**：  
    ✗ 不得重复购买保险  
    ✗ 不得报销保险费
  - 

### 2. **未参保人员**

   - 适用对象：学生/临时工/外聘专家等
   - 报销标准：
     - 每人次限购1份交通意外险
     - 单次保险费≤30元



▨▨▨

## 二、交通工具报销标准

### 2.1 费用对照表
| 交通工具类型 | 正高职称        | 副高职称        | 其他人员               |
| :----------- | :-------------- | :-------------- | :--------------------- |
| **火车**     | 软席/高铁一等座 | 硬席/高铁二等座 | 硬席/高铁二等座        |
| **轮船**     | 二等舱          | 三等舱          | 三等舱                 |
| **飞机**     | 经济舱实报      | 经济舱实报      | 经济舱实报             |
| **其他**     | 不报销          | 不报销          | 凭证报销（不含出租车） |

###  2.2 特别说明

1. **不包含费用**：出租车费、过路过桥费
2. **交通工具定义**：
   - 火车：含高铁/动车/全软席列车
   - 轮船：不含旅游船
   - 其他：含长途客车等公共交通

▨▨▨

## 三、交通工具票据要求

### 3.1 通用要求
- 必须提供正规交通票据
- 票据需包含：  
  ✓ 出行日期  
  ✓ 出发地/目的地  
  ✓ 金额信息

### 3.2 特殊要求
| 交通工具 | 票据要求                      |
|----------|-------------------------------|
| 飞机     | 需标注"经济舱"字样            |
| 火车     | 需体现席别（一等座/二等座等） |
| 其他     | 需注明具体交通工具类型        |
