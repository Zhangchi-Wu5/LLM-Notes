
[抓取新闻工作流](http://10.104.60.47/app/589da289-0e73-480d-a7d0-e46e94ed419a/workflow)

---

**1. 用户语义输入及时间范围提取**

通过 LLM 节点对用户的语义输入进行解析，从中自动识别出用户感兴趣的新闻时间范围。

• **目标**：

为后续新闻数据检索提供准确的时间参数和附加条件。

---

**2. 调用接口获取新闻信息**

• **任务描述**：

利用步骤1中提取的时间范围和其他过滤条件，构造请求参数，并调用新闻 API 接口获取对应时间段内的新闻数据。

• **具体操作**：

• 根据提取的时间范围、关键词和分类信息构造 API 请求。

• 调用新闻相关API，确保请求参数格式正确、接口返回数据符合预期。

• 获取返回的原始新闻数据，其中包含新闻标题、内容、URL、发布时间等信息。

• **目标**：

确保能够准确拉取到符合用户查询条件的新闻列表。

---

**3. 新闻内容解析与打标签**

• **任务描述**：

对接口返回的新闻数据进行深度解析，并利用 LLM 进一步抽取关键信息，同时为每条新闻打上合适的标签。

• **具体操作**：

• 将原始新闻数据传递给 LLM 节点进行自然语言处理。

• LLM 分析每条新闻内容，提取出具体信息：

1. **新闻标题**：准确反映新闻核心内容。

2. **新闻内容**：核心要点、背景信息及事实描述。

3. **新闻 URL**：原始新闻链接，便于用户获取完整报道。

4. **发布时间**：标明新闻的发布时效。

• **目标**：

为每条新闻生成结构化的关键信息，并通过标签化提升数据的可用性和查询效率。

---

**4. 输出结构化新闻列表**

• **任务描述**：

整合经过解析和标签处理后的新闻数据，生成统一格式的结构化输出结果。

• **具体操作**：

• 将所有新闻信息整合为一个列表，每条新闻数据包括：

1. **新闻标题**

2. **新闻内容摘要**

3. **新闻 URL**

4. **发布时间**

5. **新闻标签**

• 确保输出格式规范，便于前端展示或进一步的数据存储和分析。

• **目标**：

提供一份清晰、易于理解且可直接用于展示的新闻列表。
