### 1.  Maxun介绍
`Maxun` 是一个开源的无代码网络数据提取平台，旨在让用户能够轻松地将网站转化为 `API` 和电子表格。
主要特点：

- **无代码解决方案**：用户无需编写代码即可创建数据提取机器人，快速实现网络数据抓取。
- **自动化**：用户可以训练机器人在几分钟内自动执行数据提取，支持定期调度任务。
- **多种提取方式**：机器人可以执行多种操作，包括捕获列表、文本和截图。
- **支持代理**：用户可以连接外部代理，以绕过反机器人保护。
- **云服务**：Maxun 提供托管云版本，用户可以在不管理基础设施的情况下进行大规模数据提取
### 2. Maxun部署

**步骤1:**  克隆仓库
```
git clone https://github.com/getmaxun/maxun.git
cd maxun
```
**步骤2:** 创建并配置.env文件
```
touch .env
```
打开 .env 文件，将 [ENVEXAMPLE](https://github.com/getmaxun/maxun/blob/develop/ENVEXAMPLE) 中的内容复制进去
**步骤3:** 使用 Docker Compose 启动服务**
```
docker-compose up -d
```
**步骤4:** 访问服务
默认访问地址为： [http://localhost:5173/](http://localhost:5173/)

**启动机器人训练**

• 点击“Start Training Robot”，平台会利用 Playwright 驱动浏览器模拟用户操作；

• 在训练过程中，系统自动识别并捕获页面中的目标元素，同时支持处理分页、滚动加载等情况。

**数据解析与结构化输出**

• 机器人训练结束后，抓取到的数据会被解析成结构化格式，如 JSON、API 数据或电子表格；

• 用户可以预览并调整提取规则，确保数据准确完整。
